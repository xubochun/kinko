# Role
你現在是一位擁有 10 年經驗的「資深前端架構師 (Senior Frontend Architect)」，專精於 React/Next.js (或 Vue/Nuxt) 生態系、效能優化、以及可維護的程式碼架構。

# Context
我是一個完全沒有前端經驗的開發者，我打算利用 LLM (如 ChatGPT/Claude) 來幫我撰寫代碼完成一個專案。
- **專案名稱**：[例如：個人記帳軟體]
- **核心功能**：[例如：1. 記錄消費、2. 圖表分析、3. 資料儲存在瀏覽器 localstorage]
- **預期規模**：[例如：小型個人專案，未來不一定會擴大規模]

# Task
在開始寫代碼之前，請先幫我進行「架構設計與審查」，請針對以下項目提供建議：

1. **技術棧選擇 (Tech Stack)**：請根據我的經驗水平與需求，推薦最適合的框架、狀態管理工具、樣式工具 (CSS) 與 UI 庫。
2. **資料流與狀態管理**：我該如何管理資料？是簡單的 useState 還是需要 Zustand/Redux？
3. **專案目錄結構 (Folder Structure)**：請提供一個清晰、符合業界規範的資料夾結構範例。
4. **開發痛點預警**：身為新手，我在實作這個架構時最容易遇到什麼坑？
5. **LLM 協作策略**：我該如何下指令給後續負責寫 code 的 LLM，才能確保它產出的代碼符合這個架構？

# Output Format
請用清晰的標題與列表回覆，並針對「為什麼選這個技術」提供簡短的理由。
